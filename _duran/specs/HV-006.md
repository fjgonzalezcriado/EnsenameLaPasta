`Application/Services/DashboardService.cs`

Lógica:

1. Cargar capital inicial de `PortfolioOptions`.
2. Sum realized PnL de Trades.Status == Closed.
3. Para cada Trade Open: buscar último `MarketTick` de su Symbol y calcular `unrealized = (lastPrice - EntryPrice) * Quantity`.
4. CapitalActual = CapitalInicial + RealizedPnL + UnrealizedPnL.
5. TotalPnL = RealizedPnL + UnrealizedPnL.
6. Winrate = (closed con `RealizedPnL > 0`) / total closed × 100 (0 si no hay cerrados).
7. PriceSeries: por cada Symbol distinto en `MarketTick`, devolver los últimos `priceSeriesPoints` puntos ordenados por Timestamp.

```csharp
using Comillas.AITradingSimulator.Application.Common.Dtos;
using Comillas.AITradingSimulator.Application.Common.Interfaces;
using Comillas.AITradingSimulator.Application.Common.Options;
using Comillas.AITradingSimulator.Domain.Enums;
using Microsoft.EntityFrameworkCore;
using Microsoft.Extensions.Options;

namespace Comillas.AITradingSimulator.Application.Services;

public sealed class DashboardService : IDashboardService
{
    private readonly ITradingDbContext _db;
    private readonly IOptionsMonitor<PortfolioOptions> _options;

    public DashboardService(ITradingDbContext db, IOptionsMonitor<PortfolioOptions> options)
    {
        _db = db;
        _options = options;
    }

    public async Task<DashboardDto> GetSnapshotAsync(int priceSeriesPoints = 50, int recentClosedCount = 20, CancellationToken ct = default)
    {
        var capitalInicial = _options.CurrentValue.CapitalInicial;

        // Trades cerrados
        var closedTrades = await _db.Trades
            .Where(t => t.Status == TradeStatus.Closed)
            .OrderByDescending(t => t.ClosedAt)
            .Take(recentClosedCount)
            .ToListAsync(ct);

        var realizedPnL = await _db.Trades
            .Where(t => t.Status == TradeStatus.Closed)
            .SumAsync(t => (t.ExitPrice!.Value - t.EntryPrice) * t.Quantity, ct);

        var closedCount = await _db.Trades.CountAsync(t => t.Status == TradeStatus.Closed, ct);
        var winnersCount = await _db.Trades
            .Where(t => t.Status == TradeStatus.Closed && (t.ExitPrice!.Value - t.EntryPrice) > 0)
            .CountAsync(ct);
        var winrate = closedCount > 0 ? Math.Round((decimal)winnersCount / closedCount * 100m, 2) : 0m;

        // Trades abiertos
        var openTrades = await _db.Trades
            .Where(t => t.Status == TradeStatus.Open)
            .OrderBy(t => t.CreatedAt)
            .ToListAsync(ct);

        // Último precio por símbolo (necesario para unrealized)
        var symbols = openTrades.Select(t => t.Symbol).Distinct().ToList();
        var lastPriceBySymbol = new Dictionary<string, decimal>();
        foreach (var symbol in symbols)
        {
            var lastTick = await _db.MarketTicks
                .Where(t => t.Symbol == symbol)
                .OrderByDescending(t => t.Timestamp)
                .FirstOrDefaultAsync(ct);
            if (lastTick is not null) lastPriceBySymbol[symbol] = lastTick.Price;
        }

        var openDtos = openTrades.Select(t =>
        {
            var current = lastPriceBySymbol.GetValueOrDefault(t.Symbol, t.EntryPrice);
            var unrealized = (current - t.EntryPrice) * t.Quantity;
            return new OpenTradeDto(t.Id, t.Symbol, t.EntryPrice, current, t.Quantity, unrealized, t.CreatedAt);
        }).ToList();

        var unrealizedPnL = openDtos.Sum(o => o.UnrealizedPnL);

        var closedDtos = closedTrades.Select(t => new ClosedTradeDto(
            t.Id, t.Symbol, t.EntryPrice, t.ExitPrice!.Value, t.Quantity,
            (t.ExitPrice.Value - t.EntryPrice) * t.Quantity, t.CreatedAt, t.ClosedAt!.Value)).ToList();

        // Serie de precios por símbolo
        var allSymbols = await _db.MarketTicks.Select(t => t.Symbol).Distinct().ToListAsync(ct);
        var priceSeries = new List<PriceSeriesDto>(allSymbols.Count);
        foreach (var symbol in allSymbols)
        {
            var points = await _db.MarketTicks
                .Where(t => t.Symbol == symbol)
                .OrderByDescending(t => t.Timestamp)
                .Take(priceSeriesPoints)
                .OrderBy(t => t.Timestamp)
                .Select(t => new PricePoint(t.Timestamp, t.Price))
                .ToListAsync(ct);
            priceSeries.Add(new PriceSeriesDto(symbol, points));
        }

        return new DashboardDto
        {
            CapitalInicial = capitalInicial,
            CapitalActual = capitalInicial + realizedPnL + unrealizedPnL,
            RealizedPnL = realizedPnL,
            UnrealizedPnL = unrealizedPnL,
            TotalPnL = realizedPnL + unrealizedPnL,
            OpenPositions = openTrades.Count,
            ClosedTrades = closedCount,
            Winrate = winrate,
            OpenTrades = openDtos,
            RecentClosedTrades = closedDtos,
            PriceSeries = priceSeries
        };
    }
}
```

`Web/wwwroot/js/dashboard.js`

```javascript
(function () {
    const REFRESH_MS = 3000;
    let priceChart = null;

    function renderMetrics(d) {
        document.getElementById('capitalActual').textContent = d.capitalActual.toFixed(2);
        document.getElementById('capitalInicial').textContent = d.capitalInicial.toFixed(2);
        document.getElementById('totalPnL').textContent = d.totalPnL.toFixed(2);
        document.getElementById('realizedPnL').textContent = d.realizedPnL.toFixed(2);
        document.getElementById('unrealizedPnL').textContent = d.unrealizedPnL.toFixed(2);
        document.getElementById('openPositions').textContent = d.openPositions;
        document.getElementById('closedTrades').textContent = d.closedTrades;
        document.getElementById('winrate').textContent = d.winrate.toFixed(2) + '%';

        const totalPnLEl = document.getElementById('totalPnL');
        totalPnLEl.classList.toggle('text-success', d.totalPnL >= 0);
        totalPnLEl.classList.toggle('text-danger', d.totalPnL < 0);
    }

    function renderOpenTrades(trades) {
        const tbody = document.getElementById('openTradesBody');
        tbody.innerHTML = trades.length === 0
            ? '<tr><td colspan="6" class="text-center text-muted">Sin posiciones abiertas</td></tr>'
            : trades.map(t => `
                <tr>
                    <td>${t.symbol}</td>
                    <td>${t.entryPrice.toFixed(4)}</td>
                    <td>${t.currentPrice.toFixed(4)}</td>
                    <td>${t.quantity}</td>
                    <td class="${t.unrealizedPnL >= 0 ? 'text-success' : 'text-danger'}">${t.unrealizedPnL.toFixed(2)}</td>
                    <td>${new Date(t.createdAt).toLocaleString()}</td>
                </tr>`).join('');
    }

    function renderClosedTrades(trades) {
        const tbody = document.getElementById('closedTradesBody');
        tbody.innerHTML = trades.length === 0
            ? '<tr><td colspan="5" class="text-center text-muted">Sin trades cerrados</td></tr>'
            : trades.map(t => `
                <tr>
                    <td>${t.symbol}</td>
                    <td>${t.entryPrice.toFixed(4)} → ${t.exitPrice.toFixed(4)}</td>
                    <td>${t.quantity}</td>
                    <td class="${t.realizedPnL >= 0 ? 'text-success' : 'text-danger'}">${t.realizedPnL.toFixed(2)}</td>
                    <td>${new Date(t.closedAt).toLocaleString()}</td>
                </tr>`).join('');
    }

    function renderChart(series) {
        if (series.length === 0) return;

        const datasets = series.map((s, idx) => ({
            label: s.symbol,
            data: s.points.map(p => ({ x: p.timestamp, y: p.price })),
            borderColor: ['#0d6efd', '#fd7e14', '#198754', '#dc3545', '#6f42c1'][idx % 5],
            tension: 0.1,
            pointRadius: 0
        }));

        if (priceChart === null) {
            priceChart = new Chart(document.getElementById('chartPrices').getContext('2d'), {
                type: 'line',
                data: { datasets },
                options: {
                    responsive: true,
                    maintainAspectRatio: false,
                    scales: {
                        x: { type: 'time', time: { unit: 'second' } },
                        y: { type: 'linear' }
                    },
                    plugins: { legend: { position: 'top' } }
                }
            });
        } else {
            priceChart.data.datasets = datasets;
            priceChart.update('none');
        }
    }

    async function fetchAndRender() {
        try {
            const response = await fetch('/api/dashboard/data');
            if (!response.ok) return;
            const data = await response.json();
            renderMetrics(data);
            renderOpenTrades(data.openTrades);
            renderClosedTrades(data.recentClosedTrades);
            renderChart(data.priceSeries);
        } catch (err) {
            console.error('Dashboard fetch error', err);
        }
    }

    fetchAndRender();
    setInterval(fetchAndRender, REFRESH_MS);
})();
```

### Lecciones Aprendidas

1. **SQLite + decimal-as-TEXT (HV-003) impide aritmética en LINQ-a-SQL**: cuando una query expresa `Sum(t => (a - b) * c)` o `Where(t => a > b)` sobre columnas `decimal`, SQLite intenta hacer operaciones de string y devuelve resultados erróneos. Solución MVP: traer a memoria con `ToListAsync()` antes de agregar. Para queries que solo cuentan/proyectan sin aritmética (Count(t.Status), Take(N), OrderBy(time)), SQL funciona bien.
2. **`AddJsonOptions(CamelCase)` explícito en Program.cs**: aunque ASP.NET Core ya use camelCase por defecto en `[ApiController]`, los `MVC Controller` que devuelven `Json()` no siempre lo respetan automáticamente — depende de la versión. Mejor explícito.
3. **Chart.js 4 + adapter de tiempo**: el adapter `chartjs-adapter-date-fns` es OBLIGATORIO para que `type: 'time'` funcione. Sin él, el chart no se renderiza y la consola muestra "no adapter".
4. **`@section Scripts` + `Layout.cshtml`**: el template MVC genera un `_Layout.cshtml` con `@RenderSection("Scripts", required: false)`. Usar `@section Scripts { ... }` en la vista permite cargar JS específico de página al final del HTML. Buena práctica.
5. **`StaticOptionsMonitor<T>`** stub: para testear servicios que dependen de `IOptionsMonitor<T>` sin levantar todo el sistema de configuration, basta una clase interna stub que implemente la interfaz. ~10 LOC. Reusable.

### Deuda Técnica Generada

- **DT-PERF-001 (relevante si escalamos)**: `DashboardService` ahora carga todos los Trades cerrados en memoria. Con 10K+ trades cerrados sería costoso. Mejora futura: cambiar mapping de `decimal` a `REAL` en SQLite (pierde precisión, pero permite SUM/COUNT en SQL) o migrar a SQL Server / PostgreSQL.
- **DT-PERF-002 (relevante si muchos símbolos)**: el bucle de "último precio por símbolo" hace N queries. Para 3 símbolos es trivial; para 50+ habría que usar una única query con `GROUP BY Symbol` + correlated subquery `MAX(Timestamp)`.
- **DT-ARQ-001 (opcional)**: el dashboard se actualiza por polling (3s). Para una UX más fluida sería natural usar SignalR + push del bus de ticks. Fase 3.
