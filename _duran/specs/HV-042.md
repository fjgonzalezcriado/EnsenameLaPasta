## Contexto
Roadmap Fase 3: añadir **Alpha Vantage** (https://www.alphavantage.co) como 3er proveedor de datos, reutilizando el patrón ya montado para Twelve Data (feed + histórico + búsqueda + selector en runtime).

## Solución (patrón idéntico a Twelve Data)
- **`AlphaVantageOptions`** (`MarketData:AlphaVantage`: BaseUrl, ApiKey, TimeoutSeconds).
- **`AlphaVantageProvider : IMarketDataProvider`** (`GLOBAL_QUOTE`): precio + volumen. No informa divisa → la deja vacía (el generador no pisa la divisa si viene vacía). Alpha Vantage responde **HTTP 200 también en errores/límite de cuota** (detalle en `Note`/`Information`/`Error Message`): se parsea y se lanza `InvalidOperationException` con el mensaje claro → el generador loguea una línea (sin stack).
- **`AlphaVantageHistoryProvider : IMarketHistoryProvider`** (`TIME_SERIES_INTRADAY/DAILY/WEEKLY`): la clave de la serie varía ("Time Series (5min)", "Time Series (Daily)", "Weekly Time Series") → se localiza dinámicamente (JsonElement). Parsea OHLC+volumen (HV-041). Mapa rango→(función, intervalo, outputsize, nº máx.): Alpha Vantage no acepta "últimos N días", así que se recorta a los N más recientes; YTD por año en curso (`TimeProvider`). Sin key o nota de cuota → **degrada a vacío** (no lanza, no rompe el gráfico ni ensucia el log).
- **`AlphaVantageInstrumentSearchProvider : IInstrumentSearchProvider`** (`SYMBOL_SEARCH`): mapea `bestMatches` (símbolo/nombre/región→exchange/tipo). Sin key o nota → vacío.
- **Estado/selector**: `MarketProviderState.Available` añade "AlphaVantage"; los tres wrappers `Selectable*` delegan también en Alpha Vantage (switch por proveedor activo). DI registra opciones + HttpClient "AlphaVantage" + los tres concretos.
- **API**: `ProviderController` expone `alphaVantageKeyConfigured`. **UI**: opción "Alpha Vantage" en el selector de proveedor; aviso "⚠ sin API key" si falta.
- **appsettings**: sección `AlphaVantage` con `ApiKey` vacía (no commitear la key; usar user-secrets).
