## Objetivo
Que cuando el proveedor activo sea Twelve Data, también el **histórico** (barra de rangos) use Twelve Data (`/time_series`), no Yahoo. Con normalización básica de símbolos.

## Especificaciones
### Backend
- `TwelveDataHistoryProvider : IMarketHistoryProvider` (`/time_series?symbol=&interval=&outputsize=&timezone=UTC&apikey=`): parsea `values[]` (close+volume, string→decimal; datetime UTC), **invierte** a orden ascendente (Twelve Data devuelve más reciente primero). Guardas de API key y de `status:"error"`.
- Mapa rango UI → (interval, outputsize): 1D=5min/100, 5D=30min/200, 1M=1day/30, 3M/6M/1A=1day, 3A/5A=1week; **YTD** calcula outputsize por días desde el 1-ene (usa `TimeProvider`).
- `NormalizeSymbol`: cripto estilo Yahoo → barra de Twelve Data (`BTCUSD`/`BTC-USD` → `BTC/USD`, ETH análogo); el resto se pasa tal cual.
- DI: se calcula `useTwelveData` una vez (por `MarketData:ProviderType`) y selecciona **tanto el proveedor en vivo como el de histórico** (Yahoo por defecto | Twelve Data).
