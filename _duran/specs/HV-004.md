## Descripción

Implementar un `BackgroundService` (`MarketTickGeneratorService`) que genera ticks de mercado simulados con un **random-walk geométrico** (precio se mueve un % gaussiano alrededor del precio anterior) para una lista configurable de símbolos. Cada tick se persiste en la tabla `MarketTick` via `TradingDbContext`.

Esto es lo que alimenta a HV-005 (estrategia MA Crossover) y HV-006 (dashboard).

## Objetivo

Tener el simulador *vivo*: al ejecutar `dotnet run`, la BD empieza a llenarse de ticks reales (en sentido técnico — son fake pero estructuralmente válidos). Esto desbloquea desarrollo y prueba visual de HV-005 y HV-006.

### 3. `RandomWalkTickGenerator` (Infrastructure)

`Infrastructure/MarketData/RandomWalkTickGenerator.cs`

Implementa `IMarketDataProvider` con random walk geométrico:

```
next = prev * (1 + drift + volatility * gauss)
```

donde `gauss` es muestreo `Normal(0,1)`. Mantiene precio actual por símbolo en `ConcurrentDictionary` (thread-safe).

```csharp
using System.Collections.Concurrent;
using Comillas.AITradingSimulator.Application.Common.Interfaces;
using Comillas.AITradingSimulator.Application.Common.Options;
using Comillas.AITradingSimulator.Domain.Entities;
using Microsoft.Extensions.Options;

namespace Comillas.AITradingSimulator.Infrastructure.MarketData;

public sealed class RandomWalkTickGenerator : IMarketDataProvider
{
    private readonly MarketDataOptions _options;
    private readonly Random _rng;
    private readonly ConcurrentDictionary<string, decimal> _lastPrices;
    private readonly object _rngLock = new();

    public RandomWalkTickGenerator(IOptions<MarketDataOptions> options)
    {
        _options = options.Value;
        _rng = _options.Seed.HasValue ? new Random(_options.Seed.Value) : new Random();
        _lastPrices = new ConcurrentDictionary<string, decimal>(
            _options.Symbols.ToDictionary(kv => kv.Key.ToUpperInvariant(), kv => kv.Value));
    }

    public MarketTick GenerateNext(string symbol, DateTime timestampUtc)
    {
        var key = symbol.ToUpperInvariant();
        var basePrice = _lastPrices.GetOrAdd(key, 100m);

        var gauss = SampleNormal();
        var multiplier = 1m + _options.Drift + _options.Volatility * (decimal)gauss;
        var next = Math.Max(0.0001m, basePrice * multiplier);  // sanity floor

        var volume = NextVolume();

        _lastPrices[key] = next;

        return MarketTick.Create(key, Math.Round(next, 8), Math.Round(volume, 2), timestampUtc);
    }

    /// <summary>Box-Muller para muestrear Normal(0,1).</summary>
    private double SampleNormal()
    {
        double u1, u2;
        lock (_rngLock)
        {
            u1 = 1.0 - _rng.NextDouble();
            u2 = 1.0 - _rng.NextDouble();
        }
        return Math.Sqrt(-2.0 * Math.Log(u1)) * Math.Cos(2.0 * Math.PI * u2);
    }

    private decimal NextVolume()
    {
        double u;
        lock (_rngLock) { u = _rng.NextDouble(); }
        return _options.VolumeMin + ((_options.VolumeMax - _options.VolumeMin) * (decimal)u);
    }
}
```

### 4. `MarketTickGeneratorService` (Infrastructure)

`Infrastructure/MarketData/MarketTickGeneratorService.cs`

`BackgroundService` que cada `TickIntervalMs` recorre todos los símbolos configurados y genera + persiste un tick por símbolo.

```csharp
using Comillas.AITradingSimulator.Application.Common.Interfaces;
using Comillas.AITradingSimulator.Application.Common.Options;
using Microsoft.EntityFrameworkCore;
using Microsoft.Extensions.DependencyInjection;
using Microsoft.Extensions.Hosting;
using Microsoft.Extensions.Logging;
using Microsoft.Extensions.Options;

namespace Comillas.AITradingSimulator.Infrastructure.MarketData;

public sealed class MarketTickGeneratorService : BackgroundService
{
    private readonly IServiceScopeFactory _scopeFactory;
    private readonly IMarketDataProvider _provider;
    private readonly IOptionsMonitor<MarketDataOptions> _optionsMonitor;
    private readonly TimeProvider _timeProvider;
    private readonly ILogger<MarketTickGeneratorService> _logger;

    public MarketTickGeneratorService(
        IServiceScopeFactory scopeFactory,
        IMarketDataProvider provider,
        IOptionsMonitor<MarketDataOptions> optionsMonitor,
        TimeProvider timeProvider,
        ILogger<MarketTickGeneratorService> logger)
    {
        _scopeFactory = scopeFactory;
        _provider = provider;
        _optionsMonitor = optionsMonitor;
        _timeProvider = timeProvider;
        _logger = logger;
    }

    protected override async Task ExecuteAsync(CancellationToken stoppingToken)
    {
        var options = _optionsMonitor.CurrentValue;
        if (options.Symbols.Count == 0)
        {
            _logger.LogWarning("MarketData:Symbols vacío. El generador no producirá ticks.");
            return;
        }

        _logger.LogInformation(
            "Iniciando generador de ticks. Símbolos: {Symbols}. Intervalo: {Interval}ms",
            string.Join(", ", options.Symbols.Keys), options.TickIntervalMs);

        var timer = new PeriodicTimer(TimeSpan.FromMilliseconds(options.TickIntervalMs), _timeProvider);

        try
        {
            while (await timer.WaitForNextTickAsync(stoppingToken))
            {
                await GenerateAndPersistAsync(stoppingToken);
            }
        }
        catch (OperationCanceledException)
        {
            _logger.LogInformation("Generador de ticks detenido por cancelación.");
        }
    }

    private async Task GenerateAndPersistAsync(CancellationToken ct)
    {
        var options = _optionsMonitor.CurrentValue;
        var now = _timeProvider.GetUtcNow().UtcDateTime;

        using var scope = _scopeFactory.CreateScope();
        var db = scope.ServiceProvider.GetRequiredService<TradingDbContext>();

        foreach (var symbol in options.Symbols.Keys)
        {
            var tick = _provider.GenerateNext(symbol, now);
            db.MarketTicks.Add(tick);
        }

        try
        {
            await db.SaveChangesAsync(ct);
        }
        catch (Exception ex) when (ex is not OperationCanceledException)
        {
            _logger.LogError(ex, "Error persistiendo ticks de mercado.");
        }
    }
}
```

> Importa `using Comillas.AITradingSimulator.Infrastructure.Persistence;` en el using interno (`TradingDbContext`).

## Notas de implementación

- **Random walk geométrico vs aritmético**: el geométrico es estándar para precios financieros (asegura precio ≥ 0 y la magnitud de los cambios es proporcional al precio). Box-Muller es la forma clásica de muestrear Normal(0,1) sin dependencias externas.
- **Thread-safety del RNG**: `Random` no es thread-safe en .NET. Como solo hay UN background service (no concurrencia real ahora mismo), el `lock` es defensivo. Cambiar a `Random.Shared` (.NET 6+) sería simpler PERO no es seedable. Mantenemos `Random` con `lock` para conservar reproducibilidad con `Seed`.
- **`Singleton` vs `Scoped`**: el provider es Singleton porque mantiene el estado `_lastPrices` entre llamadas. El DbContext es Scoped, por eso `IServiceScopeFactory` en el hosted service.
- **`PeriodicTimer` con `TimeProvider`**: disponible en .NET 8+. Permite tests con `FakeTimeProvider`. Si no quisiéramos testabilidad, podríamos usar `Task.Delay` directo.
- **`OperationCanceledException` no se loggea como error**: es comportamiento esperado al detener el host.
- **Sin Polly aquí**: si la BD falla momentáneamente, perdemos los ticks de ese ciclo (logged como Error) pero el siguiente tick lo intenta de nuevo. No necesitamos retry para datos simulados (no son críticos). Si los hubiera (Fase 2 APIs reales), añadimos Polly.

### Lecciones Aprendidas

1. **`BackgroundService` requiere `Microsoft.Extensions.Hosting.Abstractions`**: no viene transitivamente con `Microsoft.EntityFrameworkCore.Sqlite`. Hay que añadirlo explícitamente al csproj de Infrastructure.
2. **`OptionsBuilder<T>.Bind()` requiere `Microsoft.Extensions.Options.ConfigurationExtensions`**: el paquete `Microsoft.Extensions.Options` solo da el `IOptions<T>`. El `.Bind()` está en el paquete extra.
3. **Singleton acceso a Scoped requiere `IServiceScopeFactory`**: el patrón canónico para BackgroundService que necesita DbContext es `using var scope = _scopeFactory.CreateScope(); var db = scope.ServiceProvider.GetRequiredService<TradingDbContext>();` por ciclo.
4. **`Random` no es thread-safe en .NET — `Random.Shared` sí, pero no es seedable**: tradeoff resuelto a favor de seed (necesario para tests deterministicos) con `lock` defensivo.
5. **SQLite WAL no escribe al archivo principal hasta checkpoint**: al matar el proceso con `timeout`, los ticks viven en `trading.db-wal`. El COUNT(*) funciona porque SQLite agrega WAL + DB en una vista lógica. Pero al inspeccionar tamaños de archivo, el `.db` puede parecer no haber crecido (engañoso).
6. **`PowerShell + Microsoft.Data.Sqlite` requiere dlls nativas (`e_sqlite3.dll`)**: hay que cargar desde el bin de un proyecto que ya tenga restaurado el runtime (`runtimes/win-x64/native/`). No funciona haciendo `Add-Type` directo de la dll managed sola.
