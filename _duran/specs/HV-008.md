## Contexto / Bug detectado

Smoke test real contra Yahoo (2026-06-15, pendiente desde HV-007) reveló que el endpoint usado por `YahooFinanceProvider`, `GET /v7/finance/quote?symbols=...`, **devuelve HTTP 401 Unauthorized**. Yahoo ahora exige handshake de cookie + crumb en ese endpoint; falla con cualquier User-Agent. Los 11 tests de HV-007 no lo detectaron porque usan `HttpClient` mockeado (contrato, no integración real).

Verificación en vivo:

| Endpoint | Resultado |
|---|---|
| `/v7/finance/quote?symbols=AAPL` | ❌ 401 (incluso con UA de navegador) |
| `/v8/finance/chart/AAPL?interval=1d&range=1d` | ✅ 200 — `meta.regularMarketPrice=291.13`, `meta.regularMarketVolume=37905580` |

## Objetivo

Migrar `YahooFinanceProvider` al endpoint `/v8/finance/chart/{symbol}`, que sigue sirviendo precio + volumen sin autenticación. Mantener el contrato `IMarketDataProvider` y el patrón de selección por config intactos.

## Especificaciones Técnicas

### 1. `YahooFinanceProvider` (Infrastructure)

- URL: `GET /v8/finance/chart/{Uri.EscapeDataString(symbol)}?interval=1d&range=1d`
- Parsear: `chart.result[0].meta.regularMarketPrice` y `.regularMarketVolume`.
- Validación defensiva igual que antes (sin result → throw; precio null/≤0 → throw; volume null → 0).
- Devolver `MarketTick.Create(symbol, price, volume, timestampUtc)` con el símbolo **solicitado** (no el de la respuesta), para consistencia interna.

Respuesta (estructura simplificada):
```json
{
  "chart": {
    "result": [
      { "meta": { "symbol": "AAPL", "regularMarketPrice": 291.13, "regularMarketVolume": 37905580, "currency": "USD" } }
    ],
    "error": null
  }
}
```

### 2. User-Agent (DI)

En `DependencyInjection.cs`, cambiar el UA del HttpClient `YahooFinance` de `AITradingSimulator/1.0` a uno de navegador, vía `TryAddWithoutValidation` (el string de navegador con paréntesis no pasa `UserAgent.ParseAdd`).

### 3. Tests

Reescribir `YahooFinanceProviderTests.cs` al shape `/v8/chart`:
- JSON válido / sin result / result null / precio cero / precio null / volume null → 0.
- HTTP 404 / 500 / JSON malformado (sin cambios de aserción).
- Endpoint correcto: path contiene `/v8/finance/chart/AAPL`.
- Símbolo cripto `BTC-USD` en el path.

### 4. Símbolos

Para `/v8/chart`, `AAPL`/`GOOG` valen tal cual; cripto debe ir `BTC-USD`. Default sigue `ProviderType=RandomWalk` (no se cambia el comportamiento por defecto). Se documenta en el comentario de `appsettings.json`.
