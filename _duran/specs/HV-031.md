## Objetivo
Añadir **Twelve Data** (twelvedata.com) como segundo proveedor de datos en vivo, seleccionable por configuración, reutilizando la abstracción `IMarketDataProvider`.

## Especificaciones
### Backend
- `TwelveDataOptions` (sección `MarketData:TwelveData`): `BaseUrl` (https://api.twelvedata.com), `ApiKey` (vacía por defecto; obligatoria si es el proveedor activo), `TimeoutSeconds`.
- `TwelveDataProvider : IMarketDataProvider`: endpoint `/quote?symbol=&apikey=` → precio (`close`), `volume` y `currency` en una llamada (valores numéricos llegan como string → parseo invariante). Guarda: si falta API key lanza error claro; si Twelve Data responde `status:"error"` (HTTP 200) lanza con el mensaje/código. Devuelve `MarketQuote(Tick, Currency)`.
- DI: `TwelveDataOptions` + HttpClient "TwelveData" siempre registrados. **Selector** por `MarketData:ProviderType`: `"TwelveData"` → `TwelveDataProvider`, resto → `YahooFinanceProvider` (default). El histórico (barra de rangos) sigue en Yahoo.
- appsettings: subsección `MarketData:TwelveData` con `ApiKey` vacía + comentario.

### Frontend
- El badge de proveedor mapea `TwelveData` → "Twelve Data (real)" (verde), además de Yahoo.

Para usarlo: `MarketData:ProviderType = "TwelveData"` + `MarketData:TwelveData:ApiKey` (regístrate en twelvedata.com; plan gratuito 8 req/min → subir `TickIntervalMs` si hay muchos símbolos). Los símbolos de la watchlist son estilo Yahoo (p.ej. `HY9H.F`, `^GSPC`); Twelve Data usa otras convenciones para algunos mercados → puede requerir mapeo por símbolo (fuera de alcance de este evolutivo).
