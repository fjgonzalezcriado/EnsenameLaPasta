### 2. Entidad `Trade`

`Domain/Entities/Trade.cs`

Basado en REQUERIMIENTOS.md, con setters privados y factory para invariantes:

```csharp
namespace Comillas.AITradingSimulator.Domain.Entities;

public sealed class Trade
{
    public Guid Id { get; private set; }
    public string Symbol { get; private set; } = string.Empty;
    public decimal EntryPrice { get; private set; }
    public decimal? ExitPrice { get; private set; }
    public decimal Quantity { get; private set; }
    public TradeStatus Status { get; private set; }
    public DateTime CreatedAt { get; private set; }
    public DateTime? ClosedAt { get; private set; }

    // EF Core / serialización
    private Trade() { }

    public static Trade Open(string symbol, decimal entryPrice, decimal quantity, DateTime createdAtUtc)
    {
        if (string.IsNullOrWhiteSpace(symbol))
            throw new ArgumentException("Symbol es obligatorio.", nameof(symbol));
        if (entryPrice <= 0)
            throw new ArgumentOutOfRangeException(nameof(entryPrice), "EntryPrice debe ser > 0.");
        if (quantity <= 0)
            throw new ArgumentOutOfRangeException(nameof(quantity), "Quantity debe ser > 0.");

        return new Trade
        {
            Id = Guid.NewGuid(),
            Symbol = symbol.ToUpperInvariant(),
            EntryPrice = entryPrice,
            Quantity = quantity,
            Status = TradeStatus.Open,
            CreatedAt = createdAtUtc
        };
    }

    public void Close(decimal exitPrice, DateTime closedAtUtc)
    {
        if (Status == TradeStatus.Closed)
            throw new InvalidOperationException("Trade ya está cerrado.");
        if (exitPrice <= 0)
            throw new ArgumentOutOfRangeException(nameof(exitPrice), "ExitPrice debe ser > 0.");
        if (closedAtUtc < CreatedAt)
            throw new ArgumentException("ClosedAt no puede ser anterior a CreatedAt.", nameof(closedAtUtc));

        ExitPrice = exitPrice;
        ClosedAt = closedAtUtc;
        Status = TradeStatus.Closed;
    }

    /// <summary>Profit/Loss realizado. Null si el trade aún está abierto.</summary>
    public decimal? RealizedPnL => Status == TradeStatus.Closed
        ? (ExitPrice!.Value - EntryPrice) * Quantity
        : null;
}
```

### 4. Entidad `PortfolioSnapshot`

`Domain/Entities/PortfolioSnapshot.cs`

Foto del portfolio en un instante. Se usará para el gráfico de evolución del Dashboard (HV-006). En este evolutivo solo se define; en HV-003 se persiste y en HV-006 se grafica.

```csharp
namespace Comillas.AITradingSimulator.Domain.Entities;

public sealed class PortfolioSnapshot
{
    public Guid Id { get; private set; }
    public DateTime Timestamp { get; private set; }
    public decimal Capital { get; private set; }
    public decimal RealizedPnL { get; private set; }
    public decimal UnrealizedPnL { get; private set; }
    public int OpenPositions { get; private set; }
    public int ClosedTrades { get; private set; }

    private PortfolioSnapshot() { }

    public static PortfolioSnapshot Create(
        DateTime timestampUtc,
        decimal capital,
        decimal realizedPnL,
        decimal unrealizedPnL,
        int openPositions,
        int closedTrades)
    {
        if (capital < 0)
            throw new ArgumentOutOfRangeException(nameof(capital), "Capital no puede ser negativo.");
        if (openPositions < 0)
            throw new ArgumentOutOfRangeException(nameof(openPositions));
        if (closedTrades < 0)
            throw new ArgumentOutOfRangeException(nameof(closedTrades));

        return new PortfolioSnapshot
        {
            Id = Guid.NewGuid(),
            Timestamp = timestampUtc,
            Capital = capital,
            RealizedPnL = realizedPnL,
            UnrealizedPnL = unrealizedPnL,
            OpenPositions = openPositions,
            ClosedTrades = closedTrades
        };
    }

    public decimal TotalPnL => RealizedPnL + UnrealizedPnL;
}
```

## Validaciones de negocio resumen

| Entidad | Invariante |
|---|---|
| `Trade.Open` | Symbol no vacío; EntryPrice > 0; Quantity > 0 |
| `Trade.Close` | Status != Closed; ExitPrice > 0; ClosedAt >= CreatedAt |
| `Trade.RealizedPnL` | Solo definido si Closed; `(ExitPrice - EntryPrice) * Quantity` |
| `MarketTick.Create` | Symbol no vacío; Price > 0; Volume >= 0 |
| `PortfolioSnapshot.Create` | Capital >= 0; contadores >= 0 |

## Notas de implementación

- **Inmutabilidad por encapsulación**: setters privados + factories estáticas. No usamos `record` porque las entidades EF Core necesitan constructor parameterless privado y mutabilidad controlada (para `Close`). En cambio, podría plantearse `record class` en futuro si simplificamos.
- **`DateTime` UTC explícito**: el parámetro se llama `createdAtUtc`/`closedAtUtc`/`timestampUtc` para forzar disciplina. No usar `DateTime.Now` directamente — pasarlo desde Application (que tendrá un `IClock` o `TimeProvider` en HV-004).
- **`decimal` para precios y cantidades**: nunca `double`/`float` (precisión financiera). En BD se mapeará como `decimal(18,8)` en HV-003.
- **Sin AutoMapper, sin MediatR, sin nada**: capa pura BCL.
- **El parameterless `private Trade() { }`** es necesario para EF Core (HV-003) y nuevas anotaciones de nullable: `Symbol = string.Empty` en init evita warning CS8618.

### Lecciones Aprendidas

1. **`private Trade() { }` no genera warning con NRT** si las propiedades de referencia tipo `string` se inicializan con `= string.Empty` y todas las demás son value types o nullable. EF Core podrá hidratar la entidad en HV-003 sin tocar este código.
2. **`[Theory] + InlineData(null, "", "   ")`** es muy efectivo para cubrir `string.IsNullOrWhiteSpace` con un solo método. Hace el código de test compacto y muy explícito en intención.
3. **Boundary explícito en `Close_ClosedAtIgualACreatedAt_PermiteCerrar`**: documenta una decisión sutil (la regla es `<`, no `<=`). Esto evita ambigüedad si en HV-003 alguien añade un comparador `>=` distinto.
4. **PnL negativo permitido en `PortfolioSnapshot`** mientras que `Capital < 0` no: refleja realidad financiera (pérdidas son normales, capital negativo significaría margen no cubierto, cosa que el MVP no modela).
