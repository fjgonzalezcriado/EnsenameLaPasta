## Descripción

Doble objetivo:

1. **Refinar `IMarketDataProvider`** para que sea **async** y permita implementaciones I/O-bound (llamadas HTTP). La implementación actual es síncrona porque se diseñó para el random walk en memoria; mañana puede ser Yahoo / Binance / AlphaVantage, todas async.

2. **Implementar `YahooFinanceProvider`** que consulta Yahoo Finance vía `HttpClientFactory` y devuelve `MarketTick` con datos reales. **Sin reemplazar** el random walk: ambos coexisten y se selecciona por configuración (`MarketData:ProviderType`).

> **Filosofía**: cuando aparezca AlphaVantage, será un evolutivo de ~1 archivo (`AlphaVantageProvider.cs`) + 1 línea de DI + 1 valor de config. **No** un refactor en cascada.

## Objetivo

Tras HV-007:
- `appsettings.json` → `"MarketData:ProviderType": "RandomWalk"` (default) o `"YahooFinance"` cambia la fuente sin tocar código.
- `RandomWalkTickGenerator` sigue funcionando exactamente igual (refactor mínimo).
- `YahooFinanceProvider` hace HTTP a `query1.finance.yahoo.com` y devuelve ticks reales.

- Smoke test: cambiar a YahooFinance → dashboard muestra precios reales de AAPL/GOOG/BTCUSD (cripto sigue funcionando en Yahoo).

### 5. `YahooFinanceProvider` (Infrastructure)

`Infrastructure/MarketData/YahooFinanceProvider.cs`

Usa endpoint público: `GET /v7/finance/quote?symbols=AAPL`

Respuesta (estructura simplificada):
```json
{
  "quoteResponse": {
    "result": [
      {
        "symbol": "AAPL",
        "regularMarketPrice": 173.45,
        "regularMarketVolume": 12345678
      }
    ],
    "error": null
  }
}
```

```csharp
using System.Net.Http.Json;
using System.Text.Json.Serialization;
using Comillas.AITradingSimulator.Application.Common.Interfaces;
using Comillas.AITradingSimulator.Application.Common.Options;
using Comillas.AITradingSimulator.Domain.Entities;
using Microsoft.Extensions.Logging;

namespace Comillas.AITradingSimulator.Infrastructure.MarketData;

public sealed class YahooFinanceProvider : IMarketDataProvider
{
    public const string HttpClientName = "YahooFinance";

    private readonly IHttpClientFactory _httpFactory;
    private readonly ILogger<YahooFinanceProvider> _logger;

    public YahooFinanceProvider(IHttpClientFactory httpFactory, ILogger<YahooFinanceProvider> logger)
    {
        _httpFactory = httpFactory;
        _logger = logger;
    }

    public async Task<MarketTick> GetLatestAsync(string symbol, DateTime timestampUtc, CancellationToken cancellationToken = default)
    {
        var client = _httpFactory.CreateClient(HttpClientName);

        var response = await client.GetAsync(
            $"/v7/finance/quote?symbols={Uri.EscapeDataString(symbol)}",
            cancellationToken);

        response.EnsureSuccessStatusCode();

        var payload = await response.Content.ReadFromJsonAsync<YahooQuoteResponse>(cancellationToken: cancellationToken)
            ?? throw new InvalidOperationException("Respuesta Yahoo vacía.");

        var quote = payload.QuoteResponse?.Result?.FirstOrDefault()
            ?? throw new InvalidOperationException($"Yahoo no devolvió cotización para {symbol}.");

        if (quote.RegularMarketPrice is null or <= 0)
            throw new InvalidOperationException($"Yahoo devolvió precio inválido para {symbol}.");

        var price = (decimal)quote.RegularMarketPrice.Value;
        var volume = (decimal)(quote.RegularMarketVolume ?? 0);

        return MarketTick.Create(symbol, price, volume, timestampUtc);
    }

    // DTOs para deserialización (privados al provider)
    private sealed record YahooQuoteResponse([property: JsonPropertyName("quoteResponse")] YahooQuoteResponseBody? QuoteResponse);
    private sealed record YahooQuoteResponseBody(
        [property: JsonPropertyName("result")] List<YahooQuote>? Result,
        [property: JsonPropertyName("error")] object? Error);
    private sealed record YahooQuote(
        [property: JsonPropertyName("symbol")] string Symbol,
        [property: JsonPropertyName("regularMarketPrice")] double? RegularMarketPrice,
        [property: JsonPropertyName("regularMarketVolume")] long? RegularMarketVolume);
}
```

### 6. Configuración + Registro DI

`Infrastructure/DependencyInjection.cs` selecciona el provider según `MarketData:ProviderType`:

```csharp
var providerType = configuration["MarketData:ProviderType"] ?? "RandomWalk";

switch (providerType)
{
    case "YahooFinance":
        services.AddOptions<YahooFinanceOptions>()
            .Bind(configuration.GetSection(YahooFinanceOptions.SectionName))
            .ValidateOnStart();

        services.AddHttpClient(YahooFinanceProvider.HttpClientName, (sp, client) =>
        {
            var opts = sp.GetRequiredService<IOptions<YahooFinanceOptions>>().Value;
            client.BaseAddress = new Uri(opts.BaseUrl);
            client.Timeout = TimeSpan.FromSeconds(opts.TimeoutSeconds);
            client.DefaultRequestHeaders.UserAgent.ParseAdd("AITradingSimulator/1.0");
        });

        services.AddSingleton<IMarketDataProvider, YahooFinanceProvider>();
        break;

    case "RandomWalk":
    default:
        services.AddSingleton<IMarketDataProvider, RandomWalkTickGenerator>();
        break;
}
```

> **Patrón clave**: cuando aparezca `AlphaVantageProvider`, solo se añade un `case "AlphaVantage"` y se registra el provider + HttpClient. Cero cambios en `MarketTickGeneratorService`, `IMarketDataProvider`, dashboards, tests del bus, etc.

## Notas de implementación

- **Yahoo Finance API es no-oficial**: el endpoint `query1.finance.yahoo.com/v7/finance/quote` lo usa Yahoo internamente para su web. Puede cambiar sin previo aviso. Por eso es importante que `YahooFinanceProvider` sea robusto a errores (lo es: try/catch por símbolo + EnsureSuccessStatusCode + comprobaciones de payload).
- **User-Agent obligatorio**: Yahoo bloquea peticiones sin UA real. Por eso lo añadimos en la configuración del HttpClient (`"AITradingSimulator/1.0"`).
- **Sin Polly por ahora**: si fallan llamadas individuales, perdemos un tick de ese símbolo y al siguiente ciclo lo reintenta naturalmente. No es crítico añadir retry con backoff exponencial todavía.
- **Símbolos cripto en Yahoo usan formato `BTC-USD`** no `BTCUSD`. Lo documentamos pero NO forzamos cambio en config (el usuario lo edita si activa Yahoo).
- **Rate limiting**: Yahoo no documenta límites públicos. Con `TickIntervalMs=2000` y 3 símbolos son 90 req/min — razonable. Si vemos 429 añadimos Polly.
- **Tests sin red**: `MockHttpMessageHandler` permite tests rápidos y deterministas. No tocamos la red real en CI.
- **Coexistencia de RandomWalk y Yahoo**: no son alternativas; pueden coexistir como providers seleccionables. Esto facilita demo offline (RandomWalk) y test con datos reales (Yahoo) sin cambiar código.
- **Para añadir AlphaVantage mañana**: crear `AlphaVantageProvider.cs` + `AlphaVantageOptions` + `case "AlphaVantage"` en el switch. **Ni una línea más se toca** en otros archivos. Esto es el valor de esta arquitectura.

### Resumen de Implementación

Abstracción intercambiable de providers + primera implementación real:

- **Refactor `IMarketDataProvider`**: cambio sintáctico `MarketTick GenerateNext(symbol, t)` → `Task<MarketTick> GetLatestAsync(symbol, t, ct)`. Misma semántica, async-friendly.

### Lecciones Aprendidas

1. **El patrón "switch en DI" es el mejor balance simplicidad/extensibilidad** para selección de implementaciones via configuración. Más simple que `IFactory<T>` o reflection-based, y más explícito que registrar múltiples y resolver named. Mañana añadir `case "AlphaVantage"` → cero cambios fuera del switch.
2. **Refactor sync→async de un interfaz central es de bajo riesgo si la implementación existente no hace I/O**: el `RandomWalkTickGenerator` se adaptó envolviendo el retorno en `Task.FromResult`. Sus tests cambiaron únicamente en añadir `await` y `async Task`. Cero re-pensamiento de lógica.
3. **`MockHttpMessageHandler` + `TestHttpClientFactory` (~50 LOC en total) cubren la inmensa mayoría de tests de providers HTTP**, sin necesidad de WireMock, NSubstitute extensions, o levantar HttpServer reales. Pattern reutilizable para futuros providers.
4. **`EnsureSuccessStatusCode()` lanza `HttpRequestException` con el status code en la propiedad `StatusCode`**: facilita assertions específicas de HTTP 404 vs 500 si interesa diferenciar (no es nuestro caso, basta con que falle).
5. **`System.Text.Json` + records + `JsonPropertyName`** es suficiente para deserializar JSON con propiedades camelCase. Sin necesidad de configurar `PropertyNamingPolicy` global.
6. **Validación defensiva del payload externo**: nunca confiar en que Yahoo devuelva siempre lo esperado. Comprobar `result?.FirstOrDefault()`, `RegularMarketPrice is null or <= 0`, etc. Cada chequeo lanza `InvalidOperationException` con contexto del símbolo — el catch en `MarketTickGeneratorService` lo loggea como warning y sigue con los demás símbolos del ciclo.

### Deuda Técnica Generada

- **DT-RESIL-001 (opcional, futuro)**: si Yahoo es nuestra fuente real en producción y vemos 429 ó timeouts intermitentes, añadir Polly retry policy a la pipeline del HttpClient (`AddPolicyHandler`). Ahora mismo no es necesario.
- **DT-CONFIG-001 (opcional, futuro)**: cambiar formato de símbolos automáticamente al activar Yahoo (`BTCUSD` → `BTC-USD`). Hoy se documenta y se delega al usuario. Si añadimos AlphaVantage o Binance habrá más formato divergente — podría justificarse una capa de mapping.
- **DT-ARQ-001 (opcional, futuro)**: si en algún momento queremos correr múltiples providers en paralelo (ej. AAPL desde Yahoo + BTC-USD desde Binance), el switch actual no encaja. Habría que refactorizar a registro de múltiples providers + estrategia de selección por símbolo. No urgente.
