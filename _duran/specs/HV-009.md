## Objetivo
Que la barra de rango temporal (`#rangeBar`, ya montada como UI) cargue **OHLC reales de Yahoo** para el símbolo + rango seleccionado. Los rangos largos (1M…5A) no existen en datos del simulador, así que se obtienen de Yahoo `/v8/finance/chart` con `range`/`interval`.

## Especificaciones

### Backend
- `IMarketHistoryProvider.GetHistoryAsync(symbol, range, ct)` (Application) → `IReadOnlyList<PricePoint>`.
- `YahooHistoryProvider` (Infrastructure): mapea rango→(range,interval), normaliza símbolo (BTCUSD→BTC-USD), llama `/v8/finance/chart/{symbol}?range&interval`, parsea `timestamp[]` + `indicators.quote[0].close[]` (descarta nulos).
- Mapa: 1D→(1d,5m), 5D→(5d,30m), 1M→(1mo,1d), 3M→(3mo,1d), 6M→(6mo,1d), YTD→(ytd,1d), 1A→(1y,1d), 3A→(3y,1wk), 5A→(5y,1wk).
- DI: el HttpClient "YahooFinance" + `YahooFinanceOptions` se registran **siempre** (no solo cuando el provider en vivo es Yahoo), para que el histórico funcione con RandomWalk activo.
- Endpoint `GET /api/history?symbol=AAPL&range=1M` → `PriceSeriesDto`.

### Frontend (`dashboard.js`)
- `chartMode`: 'LIVE' | rango. La vista en vivo (polling) solo redibuja el gráfico si `chartMode==='LIVE'`.
- Click en rango → `loadHistory(range)`: fetch `/api/history` por símbolo (o todos si "Todos"), `renderChart`. "En vivo" → vuelve al modo simulado.
- Cambiar de símbolo en modo histórico → recarga el histórico de ese símbolo.
- Unidad del eje X **dinámica** según el span (segundos…años), para que 1D y 5A se vean bien.

## ✅ CIERRE DEL EVOLUTIVO
- **Estado**: ✅ Completado — 2026-06-15 (sesión única)
- **Resultado**: ✅ Cumplido

### Resumen
- `IMarketHistoryProvider` (Application) + `YahooHistoryProvider` (Infra): mapa rango→(range,interval), normaliza `BTCUSD→BTC-USD`, parsea `timestamp[]`+`indicators.quote[0].close[]` de `/v8/finance/chart` (descarta nulos).
- DI: el HttpClient "YahooFinance" + `YahooFinanceOptions` se registran **siempre** (extraídos del switch), y `IMarketHistoryProvider`. El switch solo elige el provider en vivo.
- Endpoint `GET /api/history?symbol&range` → `PriceSeriesDto` (400 si rango/símbolo inválidos).
- Frontend: `chartMode` (LIVE|rango); barra `#rangeBar` → `loadHistory(range)` (fetch por símbolo, o todos si "Todos"); "En vivo" vuelve a la vista simulada; cambio de símbolo recarga histórico; eje X con unidad adaptativa (`timeUnitFor`: second…year) y `displayFormats` por unidad. El polling en vivo no toca el gráfico en modo histórico.

### Smoke test real
- `/api/history?symbol=AAPL&range=1M` → 22 puntos (298,87→291,13).
- `/api/history?symbol=BTCUSD&range=5A` → 262 puntos semanales (normalizado a BTC-USD).
- Rango inválido → HTTP 400.

89/89 verdes. Build verde con `TreatWarningsAsErrors=true`.
