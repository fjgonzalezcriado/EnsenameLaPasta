## Objetivo
Cargar la cartera real de golpe importando un CSV de compras (símbolo, precio de entrada, cantidad, fecha) en vez de teclear posición a posición.

## Modelo / formato CSV
- Columnas: `symbol, entry, qty[, date]`. Cabecera opcional (`symbol`/`simbolo`/`símbolo`).
- Delimitador: `;` si aparece en el contenido, si no `,`. (Excel español exporta con `;`, lo que permite decimales con `,`.)
- Decimales: con delimitador `;` se admite `,` como separador decimal (se normaliza a `.`); con `,` el decimal debe ser `.`. Sin separador de miles.
- Fecha (opcional): `yyyy-MM-dd`, `dd/MM/yyyy`, `dd-MM-yyyy`, ISO; vacío → ahora. Se interpreta como UTC.
- Cada fila reutiliza `PositionService.OpenAsync` (añade el símbolo a la watchlist).

## Especificaciones
### Backend
- `ImportResultDto(Imported, Failed, Errors[])` + `ImportErrorDto(Line, Message)`.
- `IPositionService.ImportCsvAsync(string csv, ct)`: parsea, valida por fila (symbol no vacío, entry>0, qty>0, fecha parseable) y abre cada posición; las filas con error se acumulan y **no** abortan el resto.
- Endpoint `POST /api/positions/import` `{ csv }` → `ImportResultDto`.

### Frontend
- Botón "📥 Importar CSV" junto a "➕ Nueva posición" → modal con: input de fichero (.csv/.txt, se vuelca al textarea), textarea para pegar, botón Importar y caja de resultados (importadas/fallidas + errores por línea). Refresca el dashboard al terminar.
