## Contexto
Ampliar el clasificador de dirección de HV-044: **más features técnicas** y un **segundo modelo** para comparar, quedándose con el mejor.

## Solución
### Features: 7 → 12
Se añaden a las 7 de HV-044: momentum 10p (`ret10`), precio vs SMA20, **MACD** histograma (EMA12−EMA26 menos señal EMA9, normalizado), **Bollinger %B**(20, 2σ) y **estocástico %K**(14). Las EMAs del MACD se precomputan sobre toda la serie. El warmup sube a `Lookback=26` y el mínimo a `MinPoints=60`.

### Modelos: SDCA + FastTree con selección por AUC
- Se entrenan **dos** candidatos sobre el mismo split cronológico 80/20: regresión logística **SDCA** y árboles con boosting **FastTree** (`Microsoft.ML.FastTree`, `NumberOfThreads=1` para determinismo, 50 árboles/10 hojas/mín. 5 por hoja).
- Cada uno se evalúa en el hold-out; se elige el de **mayor AUC** (accuracy como desempate). Se predice el último dato con el ganador.
- El DTO `DirectionSignal` gana `ModelUsed` ("SDCA" | "FastTree"). El badge de la UI muestra en el tooltip el **modelo elegido + nº de features + accuracy/AUC** del hold-out.

## Criterios de aceptación
- [x] 12 features (incl. MACD, Bollinger %B, estocástico %K, momentum 10p, SMA20)
- [x] Dos modelos (SDCA + FastTree) entrenados y comparados; se usa el de mayor AUC
- [x] `ModelUsed` reportado en el DTO y en el tooltip de la UI
- [x] `dotnet build` + `dotnet test` verdes (178/178)
